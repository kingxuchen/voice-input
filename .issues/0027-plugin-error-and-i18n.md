## What to build

把「出错时界面说什么」这件事做完整，并让文案跟随系统语言。用户遇到的每种意外，都应当得到一个**能继续往下走**的界面，而不是空白、闪烁或英文混中文。

- 四类异常各有落点：缺 helper → 安装引导（含可复制的安装命令）；读设备失败/超时 → 错误视图 + 重试；版本不兼容 → 「VoiceInput 版本过旧」+ 升级指引；操作时设备已消失 → 自动重读 + 「设备已断开，列表已刷新」。
- 加载中不渲染空态（避免真实数据回来前闪一次「无结果」）。
- 自有文案按系统语言切换中文/英文；设备名始终是系统原文。
- 从根搜索带着查询词进入命令时，列表不被该词过滤成「无结果」。

## Acceptance criteria

- [ ] 移走 helper 后显示安装空态，复制安装命令动作可用且内容正确
- [ ] 读设备失败与超时分别显示对应错误文案，重试动作可恢复
- [ ] 协议版本不匹配时显示「版本过旧」并提供升级路径，不显示设备列表
- [ ] 切换时设备已消失 → 列表自动刷新 + 「设备已断开」提示，不留死界面
- [ ] 中文系统显示中文、英文系统显示英文（`zh*` 判据），设备名保持系统原文
- [ ] 用命令名（如 `switch audio`）从根搜索进入，列表**不是**「无结果」
- [ ] 慢/空数据期间不出现空态闪烁
- [ ] 单测覆盖解析器的四种错误码映射与语言判定；`npm run build`、单测全绿
